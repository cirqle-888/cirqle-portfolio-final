# Cirqle Studio v2

Local preview: http://127.0.0.1:5176/ . The redesign is implemented in the existing website; nothing has been deployed.

## Reference direction

- Clay (https://clay.global/): primary reference for large left-aligned typography, whitespace, minimal navigation, service accordion and work-led layout.
- Metalab (https://www.metalab.com/): immersive dark visual section, interpreted as original CSS orbit artwork with pointer response and pause/play.
- Arounda (https://arounda.agency/): service-to-inquiry flow, capability grouping and clear contact entry points.
- Halo Lab (https://www.halo-lab.com/): interactive project presentation, process tabs and hover feedback.

Typography uses Manrope and Fraunces, not the references' proprietary font files. Cirqle text, brand assets and published portfolio content are retained. No reference artwork or client claims were imported. Concept projects are excluded from the client-name strip.

## Changes

New homepage, header/mobile dialog, footer, services overview, portfolio overview, about page and four service/product detail layouts. Existing portfolio galleries, reader, contact submission and service preselection remain functional. Global tokens align the remaining functional pages. Four external Unsplash hero images were removed; the application source now contains no Unsplash/Pexels URLs. CMS portfolio images are loaded from existing public data; their provenance is not independently verified.

Tokens and responsive rules are in src/styles/studio-v2.css. Shared editorial sections are in src/components/v2. Light/dark themes, reduced-motion handling, native focus feedback, image lazy loading, responsive project filters, keyboard process tabs and focus-trapped mobile navigation are included.

Homepage order: editorial hero, animated brand visual, published brand names, capabilities, selected work, process, FAQ, contact invitation, footer. Services links also expose event branding and marketing packs.

## Verification

Zero-warning lint and TypeScript checks. Production build prerenders 31 routes and 404. Static checks verify unique canonical URLs, headings, noindex 404 and compressed HTML consistency. Browser regression suite uses mocked backend responses and inquiries; it covers desktop/mobile overflow, navigation focus, contact validation and honeypot, portfolio search/pagination/retry, flyer close, accordion, filters, process keyboard navigation, animation pause and reduced motion. It does not send a live inquiry.

Pre-redesign source snapshot: /tmp/cirqle-website-before-v2.tar.gz (temporary backup; existing repository changes were preserved).

## Brand-preserving revision

Restored Cirqle's existing violet (#A259FF), cyan (#4CC3FF), dark background (#0E0C15), Inter/Outfit typography, gradients and rounded surfaces. Primary CTA gradients use darker variants for legible white labels. Hero accents, orbit artwork, project frames and process backgrounds use the brand palette.

The selected-work section now has a Metalab-inspired project-name selector: pointer hover, keyboard focus and tap select a large published-work preview with a detail-page link. On mobile, selectors scroll horizontally. Target sizes stay stable as selections change.

The portfolio now has an Arounda-inspired sidebar with service and brand filters, counts, search, removable filter tags, clear-all and empty states. Counts describe projects (a brand in a collection), not unique clients. Filters combine with AND. Industry metadata is absent from the current CMS, so the filter is honestly labelled Brands instead of inventing industry classifications. Cards continue to link to the existing galleries. No backend/schema/deployment change.
